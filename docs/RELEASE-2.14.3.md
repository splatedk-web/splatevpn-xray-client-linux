# SplateVPN Linux 2.14.3

- Интерфейсы раздачи можно выбрать выпадающим списком или отдельными кнопками.
  Добавлено обновление списка; исчезнувший выбранный адрес сохраняется с пометкой.
  Проверка портов учитывает выбранный адрес вместо всех сетей сразу.
- На главной показаны этапы подключения с временем: проверка серверов и кандидата,
  фильтры, DNS, конфигурация Xray, порты, разрешение TUN, прокси и проверка интернета.
  История сохраняется после завершения или ошибки, ожидание разрешения видно отдельно.
- GNOME/Cinnamon-прокси читается одной командой вместо девяти, записываются только
  изменённые значения. Начальный поиск и резерв проверяются группами по шесть,
  без ожидания второй последовательной группы перед выбором проверенного узла.
- При переключении сервера отображается состояние перехода и кнопка отмены.

Проверены реальная раздача HTTP на выбранном адресе с авторизацией (204) и без
пароля (407), сохранение TUN, интерфейс выбора и история этапов, восстановление
системного прокси и остальной набор Linux-проверок в GitHub Actions.

В WSL видны интерфейсы Linux (обычно eth0). Доступ к раздаче с других устройств
зависит от сетевого режима WSL и настроек Windows/роутера.

Ubuntu 24.04+, Mint 22+, Debian 13+, x86_64:

```sh
sudo apt install ./splatevpn_2.14.3-1_amd64.deb
```
