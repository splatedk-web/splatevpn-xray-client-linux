# SplateVPN Linux 2.14.2

- Убраны импорт прокси из Windows и упоминания Windows-ядра в настройках Linux.
  Внешний HTTP-прокси настраивается вручную; проверка CONNECT сохранена.
- Добавлена отдельная категория «Балансировщик» и переход к ней с главной.
- Настройки повторяют Android: три режима с пояснениями, интервалы проверки,
  подтверждения отказа, плановый поиск, пауза между улучшениями и минимальный
  выигрыш по задержке. Доступные поля зависят от режима.
- Добавлен сброс настроек балансировщика к исходным значениям.
- Ранее сохранённые нестандартные интервалы не теряются при открытии настроек.

Проверены сохранение параметров через IPC, сброс, все режимы, категории,
узкое окно и загрузка интерфейса в WebKitGTK.

Ubuntu 24.04+, Mint 22+, Debian 13+, x86_64:

```sh
sudo apt install ./splatevpn_2.14.2-1_amd64.deb
```
