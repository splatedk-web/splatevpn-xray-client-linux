# SplateVPN Linux 2.14.1

Исправлено зависание на «Подключение…» после сообщения о готовности портов Xray.
Синхронная настройка системного прокси больше не блокирует поток модели.
Это исправляет также другие действия, использующие тот же запуск Linux-команд.

Добавлены регрессионные проверки команд и полного цикла GNOME-прокси на
потоке модели, включая восстановление настроек и сохранение чужих изменений.

Ubuntu 24.04+, Mint 22+, Debian 13+, x86_64:

```sh
sudo apt install ./splatevpn_2.14.1-1_amd64.deb
```

Автозапуск, балансировщик и правила сохранения входящих соединений сохранены.
В WSL режим системного прокси действует на Linux-приложения, которые учитывают
его настройки; он не меняет прокси Windows.
