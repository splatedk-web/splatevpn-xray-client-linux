# SplateVPN Linux 2.14.0

Первый Linux-релиз на основе SplateClientDesktop 2.14.0.

- Интерфейс, подписки, профили подключения, маршруты, SmartDNS, фильтры и спидтест.
- Автоматический балансировщик с подтверждением отказа, резервом и откатом.
- TUN через polkit с сохранением входящих IPv4/IPv6 TCP-соединений и очисткой
  собственных маршрутов после отключения или смерти процесса.
- Автозапуск при входе в рабочий стол, системный прокси GNOME/Cinnamon и трей.
- Проверка новых стабильных версий в этом Linux-репозитории при запуске и вручную
  из настроек; при наличии новой версии — уведомление и переход на страницу релиза.

## Установка

**Ubuntu 24.04+, Linux Mint 22+, Debian 13+, x86_64.**

```sh
sudo apt install ./splatevpn_2.14.0-1_amd64.deb
```

Затем запустите SplateVPN из меню приложений. GUI работает от обычного
пользователя; TUN запрашивает права через polkit. Автозапуск приложения включён
по умолчанию для новых установок; это не автоматическое подключение VPN.

Готовая сборка требует glibc 2.38+, WebKitGTK 4.1 и GLIBCXX_3.4.31.
Debian 12 и Mint 21 требуют отдельной сборки нативной оболочки.
В Wayland глобальное сочетание клавиш задаётся в настройках рабочего стола
для команды `/opt/splatevpn/SplateClient --toggle`.

Проверены Ubuntu в WSL2, настоящий Xray/VLESS, политики и сценарии балансировщика,
входящие и исходящие IPv4/IPv6 в изолированных сетевых пространствах, очистка TUN,
системный прокси и запуск окна WebKitGTK. Отдельный прогон на физических
Mint Cinnamon и Debian ещё не выполнен. Kill switch в этой сборке недоступен.

Обновления проверяются автоматически, но скачивание и установка выполняются
пользователем через страницу GitHub Releases и apt.
