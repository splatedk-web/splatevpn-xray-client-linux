# SplateVPN Linux 2.14.2

- Убраны импорт прокси из Windows и упоминания Windows-ядра в настройках Linux.
  Внешний HTTP-прокси настраивается вручную; проверка CONNECT сохранена.
- Добавлена отдельная категория «Балансировщик» и переход к ней с главной.
- Настройки повторяют Android: три режима с пояснениями, интервалы проверки,
  подтверждения отказа, плановый поиск, пауза между улучшениями и минимальный
  выигрыш по задержке. Доступные поля зависят от режима.
- Добавлен сброс настроек балансировщика к исходным значениям.
- Ранее сохранённые нестандартные интервалы не теряются при открытии настроек.
- Балансировщик расположен после основных сетевых настроек, на главной показан выбранный режим.
- TUN проверяет установку помощника, устройство и права ядра до перезапуска.
  При откате показана причина, а рядом с переключателем — фактически работающий режим.
- Ошибка проверки связи отображается предупреждением; успешная проверка убирает его.
- Исправлено применение настроек при выключенном автозапуске на чистой установке.
- Геобазы обновляются и откатываются в каталоге пользователя, без записи в `/opt`;
  загруженные базы сохраняются при запуске ядра.

Проверены настоящий TUN, ручная смена сервера и автоматический резерв после
остановки VLESS-сервера, переключение прокси/TUN через IPC, восстановление ядра,
счётчики трафика и очистка маршрутов. Входящие/исходящие TCP и UDP проверены по
IPv4 и IPv6. Ядро проверило 20 сочетаний протоколов и транспортов. Дополнительно:
резервные копии, восстановление настроек, обновления, геобазы, интерфейс WebKitGTK.

Проверки выполняются в Ubuntu WSL и GitHub Actions. Полные сеансы Mint Cinnamon,
Debian и запрос пароля polkit в их окружениях пока требуют отдельного испытания.

Ubuntu 24.04+, Mint 22+, Debian 13+, x86_64:

```sh
sudo apt install ./splatevpn_2.14.2-1_amd64.deb
```
